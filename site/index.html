knime-cliBeta

Lets agents and scripts drive a running KNIME Analytics Platform from the terminal.

Early beta. knime-cli relies on KNIME internals and is pinned to KNIME Analytics Platform 5.12. Expect rough edges, and expect it to break on other KNIME versions.

GitHub repository README Releases

How it works

A small KNIME extension starts a local API inside the running Analytics Platform, listening on 127.0.0.1 only and protected by a per-session token. The knime command-line tool finds the running instance and talks to it, so you see every change appear live in the KNIME window.

1. Install the KNIME extension

  1. In KNIME Analytics Platform 5.12, open Preferences → Install/Update → Available Software Sites.
  2. Click Add…, name it knime-cli and use this location: 
    https://ben47203.github.io/knime-cli/update/
  3. Choose File → Install KNIME Extensions…, tick KNIME CLI Local API under the KNIME CLI category, and follow the wizard. Accept the prompt about unsigned content.
  4. Restart KNIME when asked.

Offline alternative

Download the update site zip from the latest release. In Available Software Sites, click Add… → Archive…, select the zip, then install as above.

2. Install the CLI

Requires Node.js 22 or later.

npm install -g knime-cli

3. Quick start

With KNIME running and a workflow open:

# check the CLI can see the running KNIME
knime status

# a tour of the commands and how agents should use them
knime guide

# print the open workflow: nodes, connections and states
knime workflow show

Requirements

  • KNIME Analytics Platform 5.12 exactly. The extension refuses to install into other versions.
  • macOS, Windows or Linux.
  • Node.js for the CLI (see above).
  • KNIME must be running with its user interface; there is no headless mode.
